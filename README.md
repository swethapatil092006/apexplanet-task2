
# ApexAuth - Login and Registration UI

## About the Project

ApexAuth is a responsive login and registration interface developed as part of the ApexPlanet Full Stack Web Development Internship.

The project provides a simple and user-friendly interface with form validation, password visibility controls, and username and email availability checking.

## Features

- Responsive design for desktop and mobile devices
- Login form with email and password validation
- Registration form with full name, username, and email fields
- Password and confirm-password matching
- Show and hide password functionality
- Username and email availability checking using the Fetch API
- Bootstrap styling and custom CSS
- Smooth scrolling and hover effects
- User-friendly validation messages

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons
- Google Fonts
- Fetch API

## Project Files

- `index.html` - Website structure and forms
- `style.css` - Styling and responsive design
- `script.js` - Form validation and interactive features
- `users.json` - Sample user data for availability checking

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install or enable the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## Note

This project is a front-end demonstration. Login does not authenticate real users, and registration does not permanently save new accounts. The sample `users.json` file is used to demonstrate username and email availability checking.
